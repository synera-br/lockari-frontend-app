# **App Name**: SecureCore Vault

## Core Features:

- Landing Page: Landing page with sections for features, pricing, contact form, and social media links.
- Contact Form Submission: Contact form that triggers a Firebase Function to send data to an email or CRM.
- Multi-Language Support: Implementation for Portuguese, Spanish, and English language support.
- Firebase Hosting: Firebase Hosting for fast and reliable delivery of the landing page.
- CI/CD Pipeline: Automated deployment pipeline using GitHub Actions for continuous integration and deployment, including build and test stages.
- Secret Deploy: CI/CD pipeline should include steps for creating Secret Manager entries, and deploying the Google Cloud Run application.

## Style Guidelines:

- Primary color: Strong blue (#29ABE2) to represent security and trust.
- Background color: Light gray (#F0F0F0) for a clean and modern look.
- Accent color: Vivid green (#90EE90) for calls to action and highlights, providing a sense of accessibility.
- Font pairing: 'Poppins' (sans-serif) for headlines, providing a modern and geometric feel. 'PT Sans' (sans-serif) for body text to ensure readability.
- Use simple, clear icons to represent different features and benefits.
- Clean, responsive layout optimized for all devices.
- Subtle animations to enhance user experience and provide feedback on interactions.
