# Lockari Vault

This is a Next.js application for Lockari Vault, a platform to securely manage secrets, keys, and certificates.

This project is built with Next.js, TypeScript, Tailwind CSS, and ShadCN UI.

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

To get started, take a look at `src/app/[lang]/page.tsx`.
